### Audacity (audio editing)
- Open: `open_app` "Audacity" with the audio file to edit. Large files take a while to import: `wait` and screenshot.
- Useful shortcuts: `ctrl+a` select all, `space` play/stop, `ctrl+z` undo, `ctrl+e` export dialog (File → Export), `ctrl+shift+e` export (varies by version), `ctrl+s` saves a project (.aup3). Effects live in the Effect menu (Normalize, Noise Reduction, Amplify, Fade In/Out).
- Export: choose the format and name in the dialog, type the full path, confirm; check the file exists afterwards.
- For simple conversions or trimming without the GUI, `run_program` ffmpeg is faster and more reliable.
