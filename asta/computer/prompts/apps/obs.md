### OBS Studio (recording and streaming)
- Open: `open_app` "OBS Studio" (name may be "OBS Studio" or "obs"). It may show an auto-configuration wizard or a "safe mode" dialog on first run: dismiss without changing settings unless the user asked.
- Start/stop recording: the "Start Recording" / "Stop Recording" buttons (bottom-right "Controls" dock). Verify with a screenshot (a red recording timer shows). Recordings go to the folder in Settings → Output (often `~/Videos`); after stopping, find the newest file with `find_files` kind video.
- Never start a **stream** (live broadcast) unless the user explicitly asked for streaming.
- Scenes and sources: use the "+" under Scenes / Sources and the dialogs that follow; confirm each dialog with `Return` after typing the name.
