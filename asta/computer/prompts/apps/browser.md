### Web browser
- `open_url` opens the default browser. Use it to *show* a page to the user or when a site is needed; for information, `search_web` is better and does not open anything.
- In the browser, the address bar is `ctrl+l`; new tab `ctrl+t`; close tab `ctrl+w`; find on page `ctrl+f`; reload `F5`.
- Do not sign in, accept cookies for the user's accounts, download or install anything, or fill forms unless the request says so.
